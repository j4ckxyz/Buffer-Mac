# Design Context: Buffer macOS Menu Bar Composer

## Target Audience & Purpose

This product is for people who want to share their thoughts and updates with ease, without getting distracted by social feeds or dashboards. It is designed to act as a distraction-free, hyper-focused posting utility that lives right in the macOS menu bar. 

While it is structured to support all standard features of a full composer (like Buffer), it is optimized primarily for text-focused platforms (Bluesky, Twitter, Mastodon, Threads) rather than heavily media-centric platforms.

---

## Brand Personality & Voice

* **Dense**: Visual margins are tight, visuals are high-information, and space is utilized efficiently. It feels like a power tool.
* **Focused**: Minimal decorations, clear composition areas, zero distracting colors or neons.
* **Smooth**: Micro-interactions are natural, transitions are quick, and drag-and-drop is highly responsive. 

Rather than attempting to be loud or artificially colorful, the app is built to feel like **Apple made it themselves**—incorporating standard system materials, native visual weight, clean layouts, and official platform behaviors.

---

## Aesthetic Direction

* **Dynamic Frosted Glass**: Uses native `NSVisualEffectView` popover vibrancy that blends dynamically with the system wallpaper and automatically adapts to **macOS Light Mode** and **Dark Mode** settings.
* **Apple Human Interface Guidelines (HIG)**: Monochromatic, system-integrated visual language. Action buttons use official system tint behaviors, badges are clean and clean-cut, and spacing respects Apple's desktop layout rhythms.

---

## Core Design Principles

1. **Intelligent Transient Popover**:
   - If the composer contains active text draft, **disable click-off auto-close**. This ensures the user can freely focus other windows (Finder, Safari, Chrome) to drag and drop text, local media, or links without the popover disappearing.
   - If the composer is empty, click-off auto-close behaves normally to keep the desktop clean.

2. **Apple-Grade Integration**:
   - Includes official system Settings and About windows to match native desktop expectations.
   - Fully supports native keyboard shortcuts (`Cmd+A`, `Cmd+C`, `Cmd+V`, `Cmd+Z`, `Cmd+,` for settings, etc.).

3. **Text-First, Media-Secondary Density**:
   - Layout is optimized to make composing text quick and spacious. Media drawers and alt-text forms are compact and only expand when active.
